# 拉曼大学与澳门大学达成合作

- Route: /6099/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/6099/

在2026澳门品牌教育展上，拉曼大学学生进展与校友联系事务副校长鍾志强教授与澳门大学校长宋永华教授正式签署合作谅解备忘录，进一步深化双方在学术领域的合作与交流。签署仪式由中国驻马来西亚大使馆欧阳玉靖先生及澳门特别行政区行政长官岑浩辉先生共同见证，澳门大学全球事务总监亦向鍾志强教授赠送纪念品，体现双方对友好合作的高度重视。本文以海报图文/图集形式发布，通过现场图片呈现签约仪式盛况。
