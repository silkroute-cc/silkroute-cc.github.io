# 征阳集团与南京中医药大学签备忘录　联手发展大马中医药中心

- Language: und

- Review Status: published

（吉隆坡21日讯）征阳集团（SUNSURIA，3743，主板产业股）与南京中医药大学签署谅解备忘录（MOU），联手发展马来西亚中医药中心。 征阳集团发文告指出，根据备忘录，双方同意共同发展中马中医药中心、合作建设中医药服务出口中心、以及发展以中医为中心的学术教育和非学术培训及其他合作。 该备忘录即日生效，有效期为5年。 来源：https://mp.weixin.qq.com/s/4ApJj4UI20tEg90syMJmZw
