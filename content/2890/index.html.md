//    从左一起，范苠僡、陈福源、符肇珍、蒋璁江、谢培根，共同推介“流韵”中国民族乐器室内音乐会。    //    - 马来西亚中国银行 -    音乐能净化人心，中国民族音乐的形成历史由来已久，经历数千年仍然在中华民族长河中熠熠发光，是文化瑰宝，值得我们继续推广和学习。   马来西亚中国银行秉持着传承和发扬中华文化的精神，特别赞助麻坡中化中学即将在6月25日举行名为“流韵”中国民族乐器室内音乐会。   麻坡中化中学是马来西亚南部一所华文独立中学，是当地华社自资办起的中学，成立于1912年4月，坚持以母语为教学媒介，传承优良中华文化，经过半个多世纪的艰苦奋斗，成就了今天中化独中的辉煌。   这一场音乐会，是由麻坡潮韵音乐社、吉隆坡广东曲艺团、吉隆坡海南八音、中化中学华乐团联合主办，届时将呈现潮州音乐、广东音乐、海南八音、江南丝竹小调及华乐室内乐。马来西亚中国银行为此音乐会的赞助单位。   马中行麻坡分行经理范苠僡在此音乐会的新闻会上对媒体表示，中国银行很乐意为弘扬中华优秀传统文化，推广中国民族音乐尽一份绵力和心意，积极践行中国银行造福社会的企业文化。      ————       扫描二维码 关注我们      微信号｜BOCMalaysia    来源：https://mp.weixin.qq.com/s/1M24WRX\_vJN6Y5aIH8YQKA
