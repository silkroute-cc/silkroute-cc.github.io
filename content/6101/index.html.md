# 【旅游】中国重庆工业旅游受到东盟游客青睐

- Route: /6101/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/6101/

连日来，中国重庆各地的工业旅游受到东盟游客青睐。新加坡、越南等国游客走进重庆，体验炒制火锅底料、参观工业机器人、与机器人一起踢足球、观看人形机器人表演等特色项目，感受重庆饮食文化与现代工业科技交融的魅力。据重庆市文化和旅游发展委员会副主任罗晓春介绍，2026年前8个月，该市接待境外游客同比增幅达56.4%。工业旅游正成为东盟游客了解中国制造与城市文化的新窗口。
