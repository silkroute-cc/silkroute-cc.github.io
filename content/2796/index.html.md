# 马来西亚交通部长：501起巴生港口入港至清关只需3天

- Route: /2796/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/2796/

（吉隆坡21日讯）交通部长拿督斯里魏家祥宣布，从5月1日起将推行新的清关标准作业程序（SOP），巴生港口货柜从入港到清关只需3天可完成。 他今日在布城交通部召开记者会表示，以往并没有规定特定的期限，因此港口难免会出现堵塞的情况。 他说，至于被扣押的货柜，调查过程则可从第3天开始，并且必须在30天内完成。 来源：https://mp.weixin.qq.com/s/y08y1tqjjYAKvXjCgUgdEg
