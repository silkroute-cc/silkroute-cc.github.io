# 中国故事系列讲座：瓷源、瓷海、瓷韵——连通世界的中国陶瓷主题讲座及瓷板画制作体验活动在马来西亚举办

适逢“文明对话国际日”，由中外文化和旅游交流中心、吉隆坡中国文化中心、马来西亚玛拉工艺大学艺术与设计学院联合主办的中国故事系列讲座：瓷源、瓷海、瓷韵——连通世界的中国陶瓷主题讲座及瓷板画制作体验活动，于6月9日至10日先后在玛拉工艺大学莎亚南校区、吉隆坡中国文化中心成功举办。 本次活动特邀陈丽芳担任主讲嘉宾。她是中国古陶瓷学会会员，深耕陶瓷文化、博物馆教育领域，主攻德化窑与外销瓷研究。曾参与编撰《中国德化瓷史》，获福建省社会科学优秀成果奖，著有《德化窑（上、中、下）》，发表文博类核心论文二十余篇
