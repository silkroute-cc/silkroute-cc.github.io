# 北京中医药大学访问拉曼大学

- Route: /6102/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/6102/

2026年9月2日，北京中医药大学中药生物技术与健康产业研究中心代表团访问拉曼大学双溪龙校区，就未来中医药及医学领域的潜在合作展开交流。拉曼大学副校长倪慕敏教授致欢迎辞，强调加强双方在健康及医学领域学术与科研合作的重要性，前马来西亚交通部长廖中莱作为特别贵宾出席。讨论环节聚焦中医药生物技术及健康产业领域的研究与开发等合作机会，为两校深化中医药与医学领域合作奠定基础。
