# 郑学方公使出席马中总商会新春联欢会

2月28日，马来西亚—中国总商会新春联欢会在吉隆坡举行。驻马来西亚使馆公使郑学方，马来西亚交通部长陆兆福、贸工部副部长沈志勤，马中总商会总会长卢国祥等嘉宾出席。 郑公使介绍了中国经济发展成就和中国外交政策，指出中国“十五五”规划将为中马务实合作提供强大动力，必将谱写高水平战略性中马命运共同体的崭新篇章。陆兆福表示，马中经贸合作空间广阔、机遇无限，希望马商界与政府密切配合，共同推动马中合作迈上新台阶。卢国祥表示，马中总商会将配合马来西亚旅游年，深化两国在旅游、服贸等领域的务实合作。
