# 拉曼大学欢迎上海电力大学代表团到访交流

- Language: und
- Type: post
- Review Status: published

拉曼大学在双溪龙校区接待中国上海电力大学代表团，双方就潜在学术合作及未来交流机会展开讨论。上海电力大学代表团由总会计师、副校级领导张川教授率领，拉曼大学则由副校长（国际与学术发展）倪慕敏教授率领相关学院及国际事务处代表出席交流。此次访问为两校提供了交流意见、探讨合作方向的平台，双方并就未来在学术交流及教育合作方面的潜在机会交换看法。

## Body

拉曼大学于今日在双溪龙校区接待中国上海电力大学代表团，双方就潜在学术合作及未来交流机会展开讨论。     上海电力大学代表团由总会计师、副校级领导张川教授率领，拉曼大学则由副校长（国际与学术发展）倪慕敏教授率领相关学院及国际事务处代表出席交流。     此次访问为两校提供了交流意见、探讨合作方向的平台，并就未来在学术交流及教育合作方面的潜在机会交换看法。
