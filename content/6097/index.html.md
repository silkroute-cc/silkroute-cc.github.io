# 商会赋能经贸合作｜陪同马来西亚驻西安总领事赴甘肃海亮新能源材料有限公司考察交流

2026年9月14日，中国马来西亚商会西安办事处主任王薇嘉陪同马来西亚驻西安总领事方若华（Farah Rakesh）一行，前往甘肃海亮新能源材料有限公司兰州新区铜箔生产基地开展专项工作考察，深入了解高端铜箔生产工艺、技术创新、产能布局及市场应用场景，围绕可再生能源领域的技术交流、资源对接、项目合作、市场互通等核心议题展开初步沟通。此次考察是商会发挥平台纽带作用的重要实践，未来将持续聚焦新能源、新材料战略性新兴产业，推动陕西、甘肃与马来西亚产业联动、共赢发展。

## Body

为深化中马新能源领域经贸交流，搭建两地企业优质合作桥梁，助推可再生能源产业双向赋能、协同发展，2026年9月14日，中国马来西亚商会西安办事处主任王薇嘉陪同马来西亚驻西安总领事方若华（Farah Rakesh）一行，前往甘肃海亮新能源材料有限公司开展专项工作考察访问。     本次考察选址甘肃海亮新能源材料有限公司兰州新区铜箔生产基地，该基地隶属于知名企业海亮集团，是区域内深耕可再生能源配套产业、助力新能源产业高质量发展的核心骨干企业，主营高端铜箔等新能源核心材料研发与生产，产业优势与市场潜力突出。     考察期间，在甘肃海亮新能源综合管理部副部长、铜箔事业部总经理原玮颢女士的热情接待与全程引导下，考察团一行实地走访了企业标准化生产车间，全方位参观核心生产线，细致了解高端铜箔的生产工艺、制作流程、技术创新、产能布局及市场应用场景，深入问询企业在新能源材料研发、产业配套、技术迭代等方面的发展成果与未来规划。   本次交流活动中，王薇嘉主任全程陪同对接，积极搭建政企、企企沟通桥梁，助力马来西亚驻华领事团队深度了解甘肃兰州新区新能源产业发展现状、企业核心优势及产业营商环境。同时，结合商会资源优势与中马产业合作趋势，双方围绕可再生能源领域的技术交流、资源对接、项目合作、市场互通等核心议题展开初步沟通，为后续双向合作落地铺垫基础。   此次考察交流，是中国马来西亚商会西安办事处充分发挥平台纽带作用的重要实践。未来，商会将持续立足中马经贸合作核心定位，聚焦新能源、新材料等战略性新兴产业，持续搭建常态化交流对接平台，积极推动陕西、甘肃西北地区与马来西亚的产业联动、资源互通、企业互访，深挖双边合作潜力，助力更多中马企业携手共赢，赋能两地新能源产业高质量协同发展。
