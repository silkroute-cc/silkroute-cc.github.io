丽阳机构与中联数据签署土地买卖合约，左起为王超文、李可婕、李廷汉、 董岩以及叶瀚鑫。   （吉隆坡9日讯）丽阳机构（TROP，5401，主板产业股）以2.40亿令吉脱售柔佛埔来土地予中联数据集团（ZDATA），以兴建数据中心。   丽阳机构向大马交易所报备子公司Tropicana Firstwide私人有限公司（TFSB）与中联数据集团旗下Computility科技（大马）有限公司（CTMSB），今日签订买卖协议，脱售有关约38.52英亩土地。   该公司表示，售地所得将用于偿还银行贷款，以及用作营运开销可发展资金。   丽阳管理层指出，将会继续支持大马愿景，推动成为全球全球数据中心站点。   “欢迎更多数据中心运营商与我们合作。不仅如此，公司在柔佛拥有超过728英亩的优质地库，不仅能继续建设城镇项目，还能寻找战略合作伙伴，共同开发这些土地。”   该公司表示，凭借高达23亿令吉的未入账销售，以及手头上认购率不错的项目来看，相信能继续扩大市场影响力并提高收益。   一同出席签土地买卖署活动的，有柔佛投资、商贸、消费人事务及人力资源委员会主席李廷汉、丽阳机构总执行长王超文、董事经理李可婕、中联数据集团创办人及总营运长，以及法律代表叶瀚鑫。   （吉隆坡9日讯）丽阳机构（Tropicana Corp Bhd）以2亿3999万令吉的价格，将柔佛一幅38.527英亩永久土地售予一家数据中心公司，为今年来第二次将该州的地皮卖给数据中心。   该集团向大马交易所报备，独资子公司Tropicana Firstwide私人有限公司已与Computility Technology（马）私人有限公司签署买卖协议。    根据报备，Computility Technology主要涉及提供托管、数据处理服务和相关活动的基础设施。     该公司由ZData Cloud Technology私人有限公司独资拥有，是北京云网络融合及数字化资讯科技（IT）基础设施服务商中联数据集团（ZData Technologies Co Ltd）的间接子公司。    这是丽阳机构在过去9个月内的第五项重大脱售。就在8月，该集团与全球IT服务商NTT Data Group达成一笔3亿8300万令吉的土地交易，出售柔佛振林山的68.457英亩土地。   在此期间，该产业集团还分别向IOI置业集团（IOI Properties Group Bhd）出售3项资产，总额达11亿1500万令吉。   这包括持股70%的丽阳名捷城购物广场（Tropicana Gardens Mall）（6亿8000万令吉）、吉隆坡W酒店（W Kuala Lumpur）（2亿7000万令吉），以及Courtyard by Marriott Penang Hotel（1亿6500万令吉）。   根据丽阳机构今日的声明，该集团目前在柔佛拥有超过728英亩的黄金地段，未入账销售为23亿令吉。   “凭着丽阳机构在柔佛的强大版图和地库，我们通过提供具良好基础设施（如水电和交通便利）的策略土地发挥有效的作用。”     来源： [阅读原文](<https://mp.weixin.qq.com/s/_sjuDgAoSBjS_AebKECi-w>)
