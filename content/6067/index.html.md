# 马来西亚首相新座驾选择中国电动车品牌

据马来西亚媒体报道，马来西亚首相安华近日选择中国极氪（ZEEKR）009豪华MPV作为新座驾出席官方活动，车牌专属化设计。该车为顶配双马达驱动版本，续航达582公里，配备按摩座椅及冷暖车载冰箱等豪华配置。目前在马来西亚售价介于29.98万至34.98万马币，体现中国品牌电动车在马来西亚高端市场的认可度。
