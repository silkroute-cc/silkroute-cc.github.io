Q1.投资马来西亚有哪些税负？    A1.马来西亚主要税项如下：   n 公司税   n 个人所得税   n 预扣税   n 不动产收益税   n 销售与服务税   n 进口税   n 国内货物税    Q2.企业若发生亏损，其损失可以在未来获利时抵减税收所得吗？    A2.自2019年税收年起，任何未吸收的营业亏损最多只能结转十个连续税收年。2018年税收年及之前财政年未吸收的营业损失可结转至2028年税收年。    Q3.马来西亚2023年企业所得税税率？    A3.自2016税收年起，公司税率为24%。   自2023税收年起，在一个税收年度的基期开始时，实缴资本／资本缴款额为250万令吉及以下，且年销售额不超过5000万令吉的居民公司和有限责任合伙企业，将按以下税率征税：   首RM150,000的可征税所得为15%；   介于RM150,001至RM600,000的可征税所得为17%；接下来的可征税所得为24%。    Q4.哪些款项支付给非居民需要在马来西亚缴纳扣缴税款？以及适用的扣缴税款税率是多少？    A4.预扣缴税款是由付款方（付款人）对非居民（收款人）赚取的收入预扣并支付给马来西亚税收局的金额。「付款人」是指在马来西亚开展业务的个人／团体以外的个人。他必须对提供的服务／技术建议／租金或根据任何动产使用协议支付给非居民收款人的其他款项扣缴税款。   付款类型 | 马来西亚所得税法，1967年 |    A5.根据1967年所得税法第7条的规定，在该税收年内居住于马来西亚至少182天的个人，将被视为税收居民。自2020税收年度起，居民扣除个人可享的减免额后，其所得税率为0%至30%。   自2020税收年度起，非居民应以30%的税率缴税，且不享有任何个人减免。    Q6.为贸易目的而进口的应税商品是否有进口税和销售税的租税优惠？    A6.进口税（一般为0%到30%）和进口销售税（0%、5%或10%）将根据进口   货物的HS编码缴纳。目前没有进口税和销售税豁免，故无法免除因贸易目的而进口的应税商品之进口税和销售税。任何到期和应付的进口税和销售税需要在海关放行前由进口商支付。但如果公司进口的货物是为进一步制造的零组件，并再出售给注册销售税制造商，则在满足某些条件的情况下，可以免征销售税。   或者，如果进口货物需要缴纳进口税，则可以考虑在各自之自由贸易协定下的优惠税率。原产于中国、东盟等国家符合条件的商品进口到马来西亚，在符合某些条件的情况下，可享受各自之自由贸易协定项下的优惠关税。为了享受优惠税率，符合条件的商品进口到马来西亚时，得出示证明相关政府机构或出口国部委颁发的资格文件（例如原产地证书）。 然而，为了在数字化时代提高业务可持续性、促进税务报告和提高合规性，马来西亚政府计划分阶段强制性要求企业采用电子发票，具体施行时间表及目标纳税义务人如下：   –2023年：将为选定的公司准备基础设施并启动试点项目。非试点企业也可自愿参与试点。   –从2024年8月1日起：年销售额达到1亿令吉以上的企业必须采用电子发票。   –2025年1月1日起：年销售额达到2,500万令吉至1亿令吉以上的企业必须采用电子发票。   –从2025年7月1日起：所有企业（分阶段）采用电子发票。   –自2024年1月1日起，其他不属于强制类别的企业可以自行采用电子发票。电子发票系统将支持使用所有文件和文书都必须使用的税号（「TIN」）。    Q9.马来西亚是否是外汇管制？    A9.根据马国央行外汇行政法规（ForeignExchangeAdministrationRules），   在马国的银行柜台或ATM皆不可提领外汇。此外，临柜不可用外汇现钞汇入马国账户，但外汇支票可以汇入马国账户。倘有外国公司以外汇汇入马国账户，马国账户将此金额转换成马币显示在该账户记录。该马国账户用户须向银行提供与公司交易往来的文件作为凭证。   马来西亚的外汇管制（FEC）受1953年外汇管制法管辖。以下是马来西亚外汇管制的要点：   1.汇款到国外   居民可以自由地以令吉向非居民进行某些付款，其中包括对令吉资产的结算，以及任何因令吉资产而产生的应收收入和利润；在马来西亚赚取的收入或费用，国内、国际商品贸易及劳务服务的结算等。居民向非居民支付的令吉款项，必须存入非居民的外部账户或非居民金融机构。   此外，居民可以自由地为任何目的（衍生品除外）向非居民支付任何金额的外币。但对海外投资另有规定。   2.非居民购买不动产   居民可向非居民提供任何数额的令吉信贷便利，以在马来西亚购买或建造住宅或商业物业，但不包括购买土地的融资。所有采购均须遵守经济规划单位之首相署的指导方针。    Q10.马来西亚公司是否可以在国外开银行账户？
