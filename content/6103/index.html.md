# 拉曼大学接待中国北京科技大学

- Route: /6103/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/6103/

拉曼大学于8月19日在双溪龙校区接待中国北京科技大学代表团，此次访问为两校搭建了宝贵的交流平台，双方就学生事务管理、人才引进、国际化办学和多校区运营等议题深入分享经验，并探讨了未来在工程、材料科学等优势学科开展学术合作的可行方向，共同推动马来西亚与中国高等教育高质量发展。拉曼大学位于马来西亚，此次接待交流进一步深化了两校间的友好合作关系。
