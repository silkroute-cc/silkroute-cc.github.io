# 北京服装学院赴马来西亚深化青年合作

- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/6121/

为推进“一带一路”框架下青年人文交流，北京服装学院校党委书记黄克瀛率团赴马来西亚走访调研，拜访马来西亚青年与体育部并调研其下属青年培训中心。马来西亚青年与体育部副部长Mordi Anak Bimol表示，中马青年交往源远流长，期待以项目为抓手深化同北服等院校机构合作，搭建中马青年产学研合作平台。黄克瀛表示，青年群体是维系两国世代友好的重要力量，北服期待完善青年教育培训、文体交流等领域协同育人机制。学校将持续推进与马来西亚院校战略合作，提升国际传播力与办学影响力。

## Body

为扎实推进“一带一路” 框架下青年人文交流，持续拓展学校国际化协同育人平台，近日，校党委书记黄克瀛率团赴马来西亚进行走访调研，拜访马来西亚青年与体育部，调研其下属青年培训中心，双方围绕青年研学培训、职业技能提升及青年交流合作等议题深入磋商，取得积极成果。     双方合影   马来西亚青年与体育部副部长Mordi Anak Bimol先生对代表团一行到访表示热烈欢迎。他表示，中马青年交往源远流长，有着良好的项目合作基础。北服是知名时尚类高校，马方期待以项目为抓手，深化同北服等院校机构的交流合作，搭建中马青年产学研合作平台，共促两国青年携手成长。     交流现场   黄克瀛对马来西亚青年与体育部的接待表示感谢。她指出，在中马高质量共建“一带一路”进程中，青年群体是维系两国世代友好的重要力量。北服期待同马来西亚相关院校、机构深化友好往来，完善青年教育培训、文体交流等领域协同育人机制，构筑中马青年互学互鉴的桥梁，推动两国青年增进理解、厚植情谊。     双方合影   代表团随后赴马来西亚青年与体育部下属培训中心实地走访，详细考察中心硬件设施、配套条件以及人才培养体系建设情况。     调研过程   以此为契机，学校将持续推进与马来西亚相关院校的战略合作，不断开辟国际化办学新路径，探索适配学校办学特色的国际人才培养范式，稳步提升北京服装学院的国际传播力与办学影响力。     双方合影
