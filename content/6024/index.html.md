# 马来西亚旅游局

- Route: /6024/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/6024/

为促进中马文化和旅游交流，青海省文化和旅游厅与吉隆坡中国文化中心近日举办“共生共享 共守的净土”中国（青海）文化旅游摄影展。展览通过40余幅作品呈现青海湖、祁连山、可可西里等自然景观及多民族文化风貌；预展和座谈交流围绕文旅合作展开。活动旨在增进马来西亚社会对青海的认识，促进两国民间文化交流，并邀请公众在展期内到吉隆坡中国文化中心观展。

## Body

为进一步促进中马文化和旅游交流合作，展示青海壮美的自然风貌与丰富的人文特色，由青海省文化和旅游厅与吉隆坡中国文化中心联合主办的“共生共享 共守的净土”中国（青海）文化旅游摄影展近日在吉隆坡开展。   6月11日，活动举办展览预展和座谈交流，中马旅游文化界嘉宾围绕文旅合作相关内容深入沟通。青海省文化和旅游厅副厅长马力现场导览，他结合展出作品，介绍青海湖、祁连山、可可西里等知名旅游目的地，讲解当地山水景致、地域风物与民族生活风貌，带领在场嘉宾与观众一同领略青海风光。     马力副厅长导览   青海幅员辽阔，景观类型丰富，多民族文化交融并存，是独具魅力的旅游目的地。本次展览精选40余幅摄影作品，多角度呈现当地自然风光、地方物产与民俗风貌，客观展现青海代表性景观、高原生活场景与地域文化，让马来西亚民众直观、全面地认识青海。   本次展览以摄影作品为载体，搭建中马文旅交流互动平台，增进马来西亚社会各界对大美青海的认知与了解，促进两国民间文化交流与友好往来。   诚邀各界朋友莅临吉隆坡中国文化中心观展，透过影像走近青海，感受雪域高原的自然风光与人文底蕴。   展览信息：     展览名称：“共生共享 共守的净土”中国（青海）文化旅游摄影展   主办单位：青海省文化和旅游厅、吉隆坡中国文化中心   展览时间：6月12日至7月11日，每日上午10时至下午4时，节假日闭馆   展览地点：吉隆坡中国文化中心       预展座谈现场
