# 孔院·活动 |砂科大孔子学院举办2026年端午节文化活动

- Route: /6019/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/6019/

为弘扬中华优秀传统文化，增进砂科大师生对中国传统节日的了解与体验，近日，砂拉越科技大学孔子学院举办“粽情端午”端午节主题文化活动。此次活动吸引了校内师生及周边社区民众积极参与，现场气氛热烈。 活动以端午节文化展示、沉浸式体验与互动游戏相结合的形式开展。 活动现场设置了端午文化展板，向参与者介绍端午节的历史渊源、屈原故事以及包粽子、佩香囊等传统习俗，帮助大家进一步了解这一重要中国传统节日的文化内涵。
