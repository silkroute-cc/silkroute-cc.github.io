# 【会议议程】数智丝路·链接未来中国—马来西亚数字经济合作与创新发展论坛

2026年9月10日，数智丝路·链接未来中国—马来西亚数字经济合作与创新发展论坛将在北京首钢园举行，由亚洲创新研究中心（AIRH）、区域策略研究所（CROSS）等机构共同主办。论坛围绕数字经济与产业合作、数字农业、可信数字技术、跨境数字合作及AI产业应用等议题展开，设置嘉宾分享、主旨演讲、创新合作案例、高端圆桌对话等环节，并将发布《中马数字经济与创新合作伙伴倡议》，揭牌中马数智创新双基地及多项产业合作行动机制，深化两国在数字经济领域的务实合作。
