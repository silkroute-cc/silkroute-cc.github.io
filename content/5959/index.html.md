# 永联物流斥资5亿令吉在马来西亚兴建OMEGA 2智能冷链物流中⼼

- Route: /5959/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/5959/

永联物流开发宣布斥资5亿令吉，在莎阿南建设OMEGA 2智能冷链物流中心。这座多楼层AS/RS冷链设施总建筑面积约57万7000平方英尺，预计2028年次季竣工，将服务食品饮料、医药、零售及电商等温控需求，并配合大马工业与能源转型目标。

## Body

（吉隆坡15日讯）领先智能物流基础设施发展商永联物流开发（ALP）斥资5亿令吉，在莎阿南兴建OMEGA 2智能冷链物流中⼼。   OMEGA 2为大⻢⾸座发展商⾃建的多楼层AS/RS冷链设施，总建筑⾯积约57万7000平⽅英尺，⾃动化存取系统（AS/RS）储位逾3万个棧板位。   此为永联物流开发在大⻢的⾸座专为冷链物流打造的智能物流基础设施，亦是其在巴⽣谷的第⼆座OMEGA项⽬，选址莎阿南南部，占地约9英亩，总投资额约5亿令吉，预计于2028年次季竣⼯。   作为多温层物流枢纽，该设施将整合多种温控区，满⾜大马⻝品与饮料、医药、零售及电商行业持续增⻓的需求。   此项⽬回应了大马市场对现代冷链设施⽇益迫切的需求，尽管温控敏感行业蓬勃发展，专业化、⾃动化冷藏仓储设施依然稀缺。   OMEGA 2智能冷链物流中心构思图。   永联物流开发大马董事经理杨添俊表示，冷链物流重要性与⽇俱增。但大⻢冷链基础设施市场在⾃动化程度、可扩展性与能源效率⽅⾯仍不⾜。   他说，OMEGA 2是由永联物流开发整合⼈⼯智能、先进机器⼈与专有科技的智慧物流基础设施平台，提供端到端供应链解决⽅案。   “OMEGA 2将填补此缺⼝，提供更智慧、更永续的冷链解决⽅案，不仅能提升营运效率，更能助⼒大⻢迈向⾼收⼊、科技驱动型经济，同时⽀持国家环境、社会和监管（ESG）与能源转型⽬标。”   OMEGA 2的核⼼设计以永续发展为原则，通过⾼密度AS/RS系统与智能能源管理系统，相较于传统冷藏仓储，该设施预计将有效降低能源消耗、优化资源利⽤，并⼤幅提升营运效率。   OMEGA 2的开发也与大⻢的国家能源转型路线图（NETR）及新⼯业大蓝图2030（NIMP 2030）⾼度契合。   两项政策均着重推动永续⼯业发展、提升能源效率，以及加速采⽤先进科技，助⼒大⻢成为区域物流与制造枢纽。   永联物流开发表示，此项⽬契合市场需求，同时⽀撑业务扩张、大⻢⻓远经济及永续⽬标基础设施需求。   获MIDA雪政府高度肯定   大⻢投资发展局（MIDA）总执行长拿督锡三苏依布拉欣对此项目深表肯定，视其为推动国家工业转型议程的重要贡献。   “其冷链设施，充分彰显第13⼤⻢计划与新⼯业大蓝图2030倡导的⾼附加值、科技驱动型投资愿景，助推动数字化转型、提升⽣产⼒与供应链韧性，同时深化国内行业链接，产⽣更⼴泛的经济溢出效益。”   他欢迎各⽅积极推动⼯业4.0落地应⽤，⽀持国家能源转型路线图，进⼀步巩固大⻢作为区域先进物流与供应链投资竞争枢纽的地位。   此外，雪兰莪也对此项⽬的重要性表示认同。   雪兰莪州投资促进机构认可此投资，与国家及雪兰莪发展愿景⾼度契合。   该机构总执行长拿督哈山阿查里承诺，将持续推动战略性投资引进，助⼒愿景早⽇成真。
