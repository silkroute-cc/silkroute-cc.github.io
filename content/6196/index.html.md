# 拉曼大学与北京交通大学展开交流

- Route: /6196/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/6196/

拉曼大学（UTAR）于2026年10月29日在双溪龙校区接待由副校长高亮教授率领的中国北京交通大学代表团。在拉曼大学校长拿督尤芳达教授的接待下，双方就海外卓越工程师学院建设、海外培训项目、学分互认、学生交换及暑期夏令营等合作方向展开交流，为两校未来的学术合作创造更多契机，并推动两校师生交流与课程衔接。

拉曼大学（UTAR）于2026年10月29日在双溪龙校区接待由副校长高亮教授率领的中国北京交通大学代表团。     双方在拉曼大学校长拿督尤芳达教授的接待下，就海外卓越工程师学院建设、海外培训项目、学分互认、学生交换及暑期夏令营等合作方向展开交流，为两校未来的学术合作创造更多契机。
