# 薛小宁副总领事出席“中沙情缘”保龄球比赛

10月4日，中国驻哥打基纳巴卢总领馆薛小宁副总领事出席“中沙情缘”保龄球比赛并向优胜选手颁奖。他表示，沙巴各大媒体为促进沙巴人民对中国的了解作出积极贡献，总领馆愿与媒体界朋友共同努力，增进中马人民理解与友谊，推动两地互利合作。本次比赛是总领馆“中沙情缘”系列文体活动之一，由总领馆与沙巴记者协会共同主办，来自沙巴十余家媒体机构的30余位新闻工作者和总领馆代表参赛。赛后，薛副总领事接受了马来西亚广播电视台（RTM）采访。

## Body

10月4日，薛小宁副总领事出席“中沙情缘”保龄球比赛，并向优胜选手颁奖。     薛副总领事表示，沙巴各大媒体为促进沙巴人民对中国的了解作出积极贡献。总领馆愿与媒体界朋友们共同努力，不断增进中国和沙巴人民之间的理解与友谊，进一步推动两地互利合作，造福两地人民，助力构建高水平战略性中马命运共同体。本次保龄球比赛是中国驻哥打基纳巴卢总领馆以“中沙情缘”为主题组织的系列文体活动之一，由总领馆和沙巴记者协会共同主办，来自沙巴十余家媒体机构的30余位新闻工作者和总领馆代表参赛。赛后，薛副总领事接受了马来西亚广播电视台（RTM）采访。
