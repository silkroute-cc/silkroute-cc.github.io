## Body

（吉隆坡17日讯）数码及通讯部副部长张念群指出，领先业界的全球超大规模数据中心供应商Vantage Data Centers将在大马投资30亿美元，建设数据中心。   “Vantage Data Centers将投资30亿美元在大马建设数据中心！”   她在面子书发文，如是表示。   此外，Vantage Data Centers亚太区营运总监基尔斯（Giles Proctor）表示，将在赛城建设数据中心，打稳赛城作为数据中心投资者首选地点的地位。   该数据中心将会提供与新加坡、曼谷和雅加达等主要城市的连接性。目前，Vantage Data Centers仍在扩建在大马的首个数据中心，当两个数据中心合并后，将提供总计287MW的科技容量，以满足超大规模企业、云端提供商和大型企业的需求。   基尔斯指出，自从Vantage Data Centers走进亚太市场后，Vantage Data Centers便一直在扩大在大马的足迹。   “我们在赛城的正面经历鼓励我们采取进一步行动，通过建设最大和超大规模的数据中心来推进国家的数码基础设施。”   早前，亚马逊云端运算服务公司（Amazon Web Services）选择马来西亚作为东南亚区域首选的数码枢纽中心，在未来15年将投资总额60亿美元（约255亿令吉）创建数据中心。   来源： [阅读原文](<https://mp.weixin.qq.com/s/OaSRJirIGfnqUPnUdb0Afg>)
