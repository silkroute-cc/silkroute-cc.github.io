# 马统计局：2021年5月份马来西亚失业率下跌至4.5%

- Route: /2700/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/2700/

《南洋商报》8月9日报道，根据马来西亚统计局的数据，2021年5月份，马来西亚的失业率下跌了0.1%至4.5%。若与2020年5月份相比，马来西亚的失业人数从82.61万人下跌至72.81万人，失业人数虽有所减少，但仍高于疫情前的50万人。
