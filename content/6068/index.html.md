# 相约马来西亚：上海、江苏、重庆、四川、陕西五省市参加第59届马来西亚MATTA FAIR国际旅游展

- Route: /6068/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/6068/

9月4日至6日，第59届马来西亚MATTA FAIR国际旅游展在吉隆坡MITEC举办。吉隆坡中国文化中心携手上海、江苏、重庆、四川、陕西五省市，以"你好！中国"主题展区亮相，集中展示中国多彩文旅资源，并通过目的地推介、非遗互动体验、行业商务洽谈等系列活动，搭建中马交流桥梁，促进两国文旅双向交流与民心相通。
