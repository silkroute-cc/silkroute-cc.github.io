# 朱兴龙总领事出席沙巴州国庆日活动

- Route: /5682/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/5682/

8月31日，应沙巴州政府邀请，朱兴龙总领事出席2025年沙巴州国庆日庆典活动，沙巴州元首敦穆萨、首席部长哈芝芝、州政府内阁成员、及州政府各部门、驻沙领团代表和各界民众逾万人参加。 活动包括升国州旗、奏唱国州歌、方阵阅兵以及文化表演等，隆重庆祝马来西亚联邦成立62周年。

## Body

8月31日，应沙巴州政府邀请，朱兴龙总领事出席2025年沙巴州国庆日庆典活动，沙巴州元首敦穆萨、首席部长哈芝芝、州政府内阁成员、及州政府各部门、驻沙领团代表和各界民众逾万人参加。     活动包括升国州旗、奏唱国州歌、方阵阅兵以及文化表演等，隆重庆祝马来西亚联邦成立62周年。
