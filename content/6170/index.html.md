# 姚文大使抵达吉隆坡国际机场的书面讲话

- Route: /6170/
- Language: und
- Type: post
- Review Status: published
- Canonical: https://silkroute.cc/6170/

中国新任第十七任驻马来西亚特命全权大使姚文抵达吉隆坡国际机场履新，并在机场发表书面讲话。他表示，中马友好源远流长，去年习近平主席成功对马进行国事访问，推动中马关系进入历史最好时期。作为新任驻马大使，他愿同马各界朋友一道，做增进政治互信与全方位友好的推动者、提升经贸合作与民生福祉的促进者、扩大人文交流与人民友好的笃行者、加强多边协作与维护国际公平正义的贡献者，推动高水平战略性中马命运共同体建设不断走深走实。

## Body

马来西亚各界朋友们：   很高兴来到“亚洲魅力所在”——美丽的马来西亚履新。我长期在亚洲地区工作，曾多次造访马来西亚，宏伟的双峰塔、可口的“猫山王”都给我留下了深刻的印象。   中马友好源远流长。明代航海家郑和5次到访马六甲、南侨机工支援中国抗战等故事家喻户晓。马来西亚是东盟成立后第一个与中国建交的成员国，也是首个推动东盟与中国开始对话进程的国家。两国人民携手应对亚洲金融危机、国际金融危机、新冠疫情冲击，守望相助、共克时艰。   中马关系已成为国与国之间相互支持、相互成就、合作共赢的典范。2025年4月习近平主席成功对马进行国事访问，中马双方一致同意构建高水平战略性中马命运共同体，推动两国关系开启新的“黄金50年”，进入历史最好时期。   作为新任驻马来西亚大使，我最重要的使命是落实好两国领导人共识，推动中马关系好上加好；最真诚的愿望是推进全方位交流合作，让两国人民亲上加亲。我愿同马各界朋友一道，做好以下几项工作：   第一，做增进政治互信与全方位友好的推动者。中国正以中国式现代化全面推进强国建设、民族复兴伟业，马来西亚也正沿着“昌明大马”道路阔步前行。中马两国利益相连、理念相通，完全可以互帮互助，助力彼此现代化之路，增进相互理解信任，推动高水平战略性中马命运共同体建设行稳致远。   第二，做提升经贸合作与民生福祉的促进者。人民对美好生活的向往，就是我们的奋斗目标。让人民过上幸福生活也是头等大事。中马经济上高度互补，合作大有可为，要继续高质量共建“一带一路”，巩固基建、贸易等传统领域合作，打造人工智能、半导体等新的合作亮点，让两国人民获得更多实实在在的好处。   第三，做扩大人文交流与人民友好的笃行者。国之交在于民相亲，民相亲在于心相通。中马友好的最大优势在于得到两国民众的拥护和支持，有广泛的社会共识。要用好用足免签红利和马来西亚旅游年契机，办好“儒伊文明对话”，广泛开展教育、文化、医疗、旅游、地方等各领域交往，为两国民众往来提供更多便利，更加相知相亲。   第四，做加强多边协作与维护国际公平正义的贡献者。当前，百年变局加速演进，单边霸凌逆流涌动，但是人类社会命运相关，休戚与共，这是时代潮流、历史大势。中马要共同维护以联合国为核心的国际体系，共同坚守公平正义的价值追求，共同壮大全球治理的南方力量，共同坚持开放发展的正确方向，共同完善新兴领域的治理规则，为动荡不安的世界注入更多宝贵的确定性。   中马关系宏伟的蓝图已经绘就，前进的号角已经吹响。时间不等人！历史不等人！我将在新征程上跑好历史接力棒，与各界朋友深入交流，相互启迪，共谋深化合作之策，共聚促进合作之力，共创互利合作之势，让中马世代友好薪火相传、发扬光大。
